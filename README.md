# CutClean Reborn

CutClean Reborn is a Minecraft UHC/gameplay-rules project maintained per platform and game version.

## Branches

- `fabric/1.21.11` — Fabric mod for Minecraft 1.21.11.
- `paper/26.3` — Paper plugin for Minecraft 26.3.

Each version branch contains its own Gradle project at the repository root, mirroring the version-branch layout used by the other Zazac1 Minecraft repositories.

## Local workspace

The `main` branch keeps both version projects side by side for development:

- `Fabric_1.21.11/`
- `Paper_26.3/`

Generated Gradle files, test worlds, logs and local Paper servers are intentionally excluded from Git.
